# Login page

Status: implemented · Owner: Bacter Sidonia

This is an example spec. Keep its four sections for your own specs and
replace the content. One file per feature.

## Goal

A registered user signs in to the app with e-mail and password.

## Out of scope

- No "Forgot password" (comes later).

## Behavior

- [x] Given a valid e-mail and the correct password, when I press "Login",
      I land on the home page.
- [x] With an empty field, the "Login" button is disabled.
- [x] With an invalid e-mail format, when I press "Login", I see an e-mail
      validation message.
- [x] With incorrect credentials, when I press "Login", I see a general error
      message that does not reveal which credential is incorrect.
- [x] I can show and hide the password I entered with a toggle beside the
      password field.

## Done when

- [x] every behavior line has been checked
